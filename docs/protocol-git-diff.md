# Git changes in an agent workspace

Protocol authority: Paseo commit [`940dbfd242ce132d18113fa596c6115d8e96e442`](https://github.com/getpaseo/paseo/tree/940dbfd242ce132d18113fa596c6115d8e96e442), checked 2026-09-28. The relevant [wire schemas](https://github.com/getpaseo/paseo/blob/940dbfd242ce132d18113fa596c6115d8e96e442/packages/protocol/src/messages.ts) define `checkout_status_request`/`checkout_status_response` and `checkout.diff.get.request`/`checkout.diff.get.response`; the [TypeScript client](https://github.com/getpaseo/paseo/blob/940dbfd242ce132d18113fa596c6115d8e96e442/packages/client/src/daemon-client.ts) uses the same correlated requests. Paseo's [architecture](https://github.com/getpaseo/paseo/blob/940dbfd242ce132d18113fa596c6115d8e96e442/docs/architecture.md) keeps the checkout on the daemon host. Its [compatibility contract](https://github.com/getpaseo/paseo/blob/940dbfd242ce132d18113fa596c6115d8e96e442/docs/protocol-compatibility.md) permits additive fields and requires clients to tolerate unknown response fields.

Oesap sends the selected agent's `cwd` in `checkout_status_request` and only requests a diff when `isGit` is true. It then sends `checkout.diff.get.request` with `compare.mode: "uncommitted"`. The response contains the full changed-file list, each file's addition/deletion counts, and parsed hunks. There is no per-file diff RPC or plus/minus field in the status response. Oesap sums the file counts and reconstructs a readable unified diff for each file from those hunks. Paseo's [diff parser](https://github.com/getpaseo/paseo/blob/940dbfd242ce132d18113fa596c6115d8e96e442/packages/server/src/server/utils/diff-highlighter.ts) includes the hunk header as a `header` line and strips add/remove/context prefixes from line content; Oesap preserves the header and restores those prefixes for display. The file view reads the returned snapshot locally. A refresh requests a new snapshot.

Neither request has a `server_info.features` gate in the consulted schema. An older daemon may reject or time out on these requests; Oesap shows an unavailable state and a retry action. It also reports non-Git workspaces, host errors, and oversized diffs rather than displaying misleading totals. Binary files and files whose diff is too large remain in the file list with an explanatory detail view. Responses from a prior connection or selected thread cannot replace the current snapshot.

The app does not run Git on the Apple device. It sends no shell commands and treats returned paths, hunks, and error text as display-only data. Sanitized protocol and adapter fixtures cover request shape, correlation, parsed hunks, and aggregate counts.
